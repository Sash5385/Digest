blockWritesOutsideWorkingDirectories Стоит включить v2.1.314
Что это
Настройка прав: Claude не сможет записывать файлы за пределами рабочих папок проекта.
Зачем
Защита от случайных правок в соседних проектах, домашней папке или системных файлах, особенно когда агент работает без постоянных подтверждений.
Как

Добавь в .claude/settings.json проекта или в ~/.claude/settings.json для всех проектов:

{
  "permissions": {
    "blockWritesOutsideWorkingDirectories": true
  }
}

Значение true выведено из названия, в changelog оно не показано. Проверь в документации.

CLAUDE_CODE_SUBAGENT_EFFORT Экономия токенов v2.1.316
Что это
Переменная окружения, которая задаёт уровень «усилий» (глубину рассуждений) для субагентов отдельно от основной сессии.
Зачем
Субагенты часто делают простую работу: поиск по коду, чтение файлов. Низкий уровень для них снижает расход токенов и ускоряет ответы, а основная сессия остаётся на полной мощности.
Как

PowerShell, на текущую сессию:

$env:CLAUDE_CODE_SUBAGENT_EFFORT = "low"
claude

Допустимые значения в changelog не указаны. low здесь пример, список проверь в документации.

Idle compaction Удобство v2.1.302 · v2.1.314
Что это
Автоматическое сжатие длинного чата, когда ты надолго отошёл. В v2.1.314 оно появилось в VS Code и на вкладке Code в Desktop.
Зачем
Контекст не раздувается между подходами к работе, возвращаться к длинной сессии дешевле и быстрее.
Как
Открой /config и найди параметр Idle compaction. Включи его, если он выключен.
Fast mode на Opus 4.8 Дедлайн 30 ноября v2.1.316
Что это
Быстрый режим для Opus 4.8 объявлен устаревшим. 30 ноября 2026 его уберут.
Зачем знать
Если у тебя есть привычка или скрипты с этим режимом, после даты они перестанут работать как раньше.
Что делать
Заранее перейди на обычный режим или другую модель. Если нигде не используешь, ничего делать не нужно.
/auto-mode-setup Попробовать v2.1.304
Что это
Команда для настройки автоматического режима (auto mode), в котором Claude меньше спрашивает подтверждения.
Зачем
Быстрее проходят рутинные задачи вроде тестов, правок и линтинга. Лучше сочетать с настройкой выше про запрет записи вне проекта.
Как
Введи /auto-mode-setup в сессии и следуй подсказкам. Подробностей работы мастера в changelog нет.
Субагенты и поздно подключённые MCP К сведению v2.1.311
Что это
Субагент теперь видит инструменты MCP-серверов, которые закончили подключение уже после его запуска.
Зачем
Меньше случаев, когда субагент не находит нужный инструмент только потому, что сервер стартовал медленнее.
Как
Ничего включать не нужно, работает само.
Исправления MCP К сведению v2.1.307 · v2.1.314
Что исправлено

HTTP-вызовы MCP больше не отправляются дважды: повторяются только безопасные (read-only или идемпотентные).

Серверы без авторизации не показывают ложное «needs authentication». Команда claude mcp logout больше не сообщает об успехе, когда выход не удался.

Как
Обнови Claude Code до последней версии.
Monitor tool и корпоративные настройки Если актуально v2.1.310–316
Что это
Monitor tool и плагин-мониторы заработали на Bedrock, Vertex и Foundry. Для команд добавили групповые бюджеты, маршрутизацию по группам IdP и OIDC-настройки.
Кому нужно
Тем, кто работает через облачных провайдеров или внутренний шлюз компании. Если используешь Claude Code напрямую, пропускай.

Лайфхаки

Связка безопасности. blockWritesOutsideWorkingDirectories плюс auto mode: агент работает самостоятельно, но не выходит за границы проекта.

Дешёвые субагенты. Если в проекте много агентов в .claude/agents, снизь им уровень усилий через CLAUDE_CODE_SUBAGENT_EFFORT и сравни расход токенов.

Постоянная переменная. Чтобы не вводить её каждый раз, задай на уровне пользователя:

[Environment]::SetEnvironmentVariable("CLAUDE_CODE_SUBAGENT_EFFORT", "low", "User")
